# Architecture Decision Records

ADRs capture decisions that affect protocol interoperability, security,
operability, or long-term product shape.

Each ADR must distinguish:

- `PROTOCOL REQUIREMENT`
- `IMPLEMENTATION CHOICE`
- `INITIAL DEFAULT`
- `FUTURE OPTION`
